# خانواده برداشت — مخزن پروژه

سایت و پنل آموزشگاه رایگان بازیگری سینما «خانواده برداشت» — دامنهٔ `bardashtt.com`.

کل محصول **یک اپلیکیشن Next.js** است. هیچ فایل HTML یا PHP جداگانه‌ای سرو نمی‌شود.

---

## نقشهٔ مخزن

```
/
├── nextjs/                 ← اپلیکیشن اصلی (سایت عمومی + داشبورد + پنل مدیریت + API)
│                             راهنمای کامل: nextjs/README.md
│
├── tools/                  ← ابزارهای جانبی که بخشی از اپ نیستند
│   ├── db-backup.sh        ← بکاپ روزانهٔ دیتابیس (روی سرور اجرا می‌شود)
│   └── book-pipeline/      ← خطِ آماده‌سازی متن کتاب و بانک سؤال آزمون
│       ├── data/           ← فایل‌های متنی ورودی/خروجی همین خط
│       └── README.md
│
├── outputs/                ← خروجی‌های تولیدشده (OCR کتاب، PDF منبع، تصاویر بازبینی)
└── uploads/                ← فایل‌هایی که در گفت‌وگو پیوست شده‌اند (اسکرین‌شات‌ها)
```

> `nextjs/uploads/` فایل‌های آپلودیِ کاربران سایت است و عمداً در گیت نیست
> (`.gitignore`)؛ نسخهٔ معتبر آن روی سرور زندگی می‌کند.

---

## سرور و محیط‌ها

| محیط | مسیر روی سرور | توضیح |
|---|---|---|
| زنده | `/var/www/bardasht-nextjs` | همین چیزی است که کاربر می‌بیند؛ روی پورت ۳۰۰۰ پشت nginx |
| آزمایشی | `/var/www/bardasht-nextjs-staging` | فقط برای بیلد و تست؛ ترافیک عمومی ندارد |

- سرویس: `bardasht-nextjs.service` (systemd)
- وب‌سرور: nginx با SSL از Let's Encrypt
- دیتابیس: PostgreSQL (زنده و آزمایشی **یک دیتابیس مشترک** دارند — در تغییر اسکیمای دیتابیس باید حواسمان باشد)
- بکاپ دیتابیس: `~/db-backups/` روی سرور
- نقطه‌های برگشت کد: `~/rollbacks/` روی سرور
- آرشیو چیزهای بازنشسته‌شده: `~/archive/` روی سرور

## قانون بیلد

بیلد **همیشه روی سرور** انجام می‌شود، نه در محیط توسعه.
روال کامل و امن در `nextjs/README.md` بخش «بیلد و استقرار» توضیح داده شده است.
